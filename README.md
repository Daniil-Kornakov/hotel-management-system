# Лабораторная работа №2

## Тема

Классы, агрегация и композиция. Язык программирования с ручным управлением памятью.

## Тема проекта

Проектирование системы управления гостиницей.

## Классы

Service — услуга гостиницы.

ServiceOrder — заказ услуги.

Booking — бронирование.

## Связи между классами

### Композиция

Booking — ServiceOrder.

Класс Booking хранит указатели на принадлежащие ему заказы услуг в m_orders.

При уничтожении бронирования его деструктор удаляет все заказы.

### Агрегация

ServiceOrder — Service.

Класс ServiceOrder хранит указатель const Service* m_service на услугу, созданную отдельно.

После уничтожения заказа объект Service продолжает существовать.

Услуга должна существовать дольше использующего её заказа.

## Правила программы

- цена услуги не может быть отрицательной;
- количество единиц услуги должно быть положительным;
- начать проживание можно только по подтверждённому бронированию;
- завершить можно только начатое проживание;
- отменить можно только подтверждённое бронирование;
- услуги можно добавлять только во время проживания;
- завтрак для люкса включён в стоимость и повторно не оплачивается;
- цена услуги фиксируется при оформлении заказа.
